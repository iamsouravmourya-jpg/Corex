## 🌐 Executive Overview

**Corex Studio** (developed by **LernexAI**) is a zero-latency creative design engine that runs at a native **60FPS** directly in the browser. ## 💎 Flagship Subsystems & Engineering Breakdown

### 1. 🎨 LernexAI Deep Ink & Electric Cyan Design System (`src/index.css`)
* **Midnight Ink Surface Hierarchy**: Engineered around `#08090E` (`ink-950`), `#0D0F17` (`ink-900`), `#11141C` (`ink-800`), and `#1A1E2A` (`ink-700`) for zero eye strain and maximum color fidelity.
* **Luminous Accent Tokens**: Powered by Electric Cyan (`#06B6D4`), Teal (`#14B8A6`), Emerald (`#10B981`), Amber (`#F59E0B`), and Rose (`#F43F5E`).
* **Dual Editorial Typography**: **Plus Jakarta Sans** for precision UI geometry paired with **Playfair Display** (italic serif) for luxury editorial headlines.

### 2. ⌘K Omnibar Command Palette (`src/components/command/CommandPalette.tsx`)
* **Instant Keyboard-Driven Execution (`⌘K` / `Ctrl+K`)**: Search and trigger 20+ studio operations in milliseconds—insert parametric vectors, apply full-canvas color themes, distribute objects, run background cutouts, or trigger 2x HD exports.

### 3. 📐 Parametric Vector Lab, Guilloche Meshes & QR Studio (`src/lib/vectorStudio.ts`)
* **Parametric Polygons & Starbursts**: Generate editable 5-Point Stars, 8-Point Seals, Hexagons, Octagons, and shaded **3D Isometric Cubes** (`Group` of 3 vector faces).
* **Corel/Illustrator Procedural Meshes**: 1-click generation of **Cyber Wave Bezier Meshes**, **Guilloche Spirograph Rosettes**, **Concentric Vector Halos**, and **Golden Ratio ($\varphi = 1.618$) Fibonacci Spirals**.
* **Client-Side Vector QR Matrix Generator**: Encodes any URL or string into a crisp, infinitely scalable 21×21 vector QR badge directly on the artboard.

### 4. ✂️ Client-Side Smart Chroma Cutout & Studio LUT Shaders (`src/lib/vectorStudio.ts`)
* **Zero-Server Alpha Background Removal**: Samples corner pixels or strips white/dark backgrounds with smooth edge feathering directly in browser HTML5 `<canvas>` memory.
* **1-Click Studio Color Grading LUTs**: Instant **Cyberpunk**, **Noir Monochrome**, **Cinema Gold**, and **Arctic Cool** shader pipelines alongside granular Brightness, Contrast, Saturation, and Gaussian Blur sliders.

### 5. 💻 Figma Dev Mode — Live CSS Inspector (`src/components/panels/PropertiesPanel.tsx`)
* **Real-Time CSS Synthesis**: Inspect any selected vector, text, or image node to view and copy production-ready CSS (`position`, `width`, `height`, `transform`, `background`, `border-radius`, `mix-blend-mode`, `font-family`).

### 6. ⚡ Binary Transaction Command Ledger (`src/lib/commandLedger.ts` & `src/store/editorStore.ts`)
* **ZLIB/DEFLATE Binary Compression (`pako`)**: Every canvas state transition is deflated into compact `Uint8Array` binary packets (`encodeSceneTransaction` / `decodeSceneTransaction`), providing a 64-frame undo/redo ledger (`⌘Z` / `⌘⇧Z`).

### 7. 🤖 Hybrid Serverless + Gemini 3.8/3.1 Flash AI Studio (`src/components/ai/AiChatPanel.tsx` & `src/lib/serverlessAi.ts`)
* **Text-to-Design Autonomous Layout**: Generates complete multi-layer posters, banners, and thumbnails from natural language prompts.
* **AI Image Creation & Editing**: Synthesizes custom artwork via `gemini-3.1-flash-image-preview` with automatic client-side serverless SVG synthesis fallback.
* **Vision Design Doctor**: Evaluates canvas contrast, hierarchy, and alignment with 1-click color palette application.
